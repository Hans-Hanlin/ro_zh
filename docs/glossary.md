## 格式規則
- `{n}`、`{max}`、`{0}` 這類佔位符**原樣保留**，可以調整位置。
- HTML 標籤（`<b>`、`<br>`、`<span ...>`）原樣保留。
- 數字、`%`、`+`、`·`、`/`、`↗`、表情符號原樣保留。
- 用台灣用語：「資訊」不用「信息」、「設定」不用「設置」、「品質」不用「質量」、「視窗」不用「窗口」。
- 對白口語、自然，不要翻譯腔；UI 短詞要短。
